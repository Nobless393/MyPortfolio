Proyecto destacado · Full-stack

DanzaBogota

GitHub

Plataforma web para la gestión de eventos de danza cultural en Bogotá. Sistema completo con autenticación JWT, control de roles (Admin, Gestor y Grupo), inscripciones a eventos, gestión de grupos y participantes, comentarios, categorías y localidades. Backend construido con arquitectura limpia en capas.

C# .NET 8 EF Core SQL Server JWT + Identity Serilog FluentValidation Swagger React 18 TypeScript Vite Axios

¿Por qué este proyecto?

Es mi proyecto de tesis en Ingeniería de Sistemas (UNAD). Nació del interés por dar visibilidad a los grupos de danza folclórica y cultural de Bogotá, que organizan y promocionan sus eventos de forma dispersa. Quería un sistema donde un administrador publique eventos, los grupos se inscriban y los gestores administren participantes e inscripciones, todo con roles y seguridad reales. No es solo un ejercicio académico: es una plataforma que resuelve un problema concreto de mi ciudad.

Backend — .NET 8 Web API

  • Arquitectura limpia en capas (Application, Domain, Infrastructure, Transversal)
  • Auth JWT con ASP.NET Core Identity y roles personalizados
  • EF Core con migraciones y seeding de datos de referencia
  • Validación con FluentValidation y filtro global de validación
  • Logging con Serilog y middleware global de excepciones
  • 10+ controllers: Auth, Events, Groups, Participants, Inscriptions, Comments y más
  • Documentación con Swagger / OpenAPI

Frontend — React + TypeScript

  • SPA con Vite, React Router v6 y Axios
  • Interceptor de JWT para peticiones autenticadas
  • Rutas protegidas por rol (Admin / Gestor / Grupo)
  • Vistas por rol: dashboard, CRUD de eventos, inscripciones, grupos, usuarios
  • Página pública de eventos con detalle e inscripción
  • Tipos TypeScript alineados con los DTOs del backend
  • Proyecto de tesis — Ingeniería en Sistemas (UNAD)
  • Backend y frontend desplegables por separado, con proxy de desarrollo en Vite
  • Semilla con datos de prueba y credenciales de administrador
